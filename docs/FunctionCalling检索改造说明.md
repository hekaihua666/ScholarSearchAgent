# Function Calling 检索改造说明

## 已实现机制

网页发送 `search_strategy=agent`。模型根据原始问题、已有论文、历史动作和剩余预算，自主选择工具；后端验证参数后执行，将真实结果作为 `role=tool` 消息返回；模型再决策，直到主动结束或触及预算。

没有预设必须执行几轮，也没有固定的搜索、语义、引文调用顺序。模型可以一次搜索后结束，也可以切换工具连续搜索。

## 工具与结果

- `search_papers(query, source, limit)`：主检索及备用来源，或 arXiv 预印本搜索。
- `semantic_search(query, limit)`：使用已有 OpenAlex 语义接口。
- `expand_citations(paper_id, direction, limit)`：围绕已获取论文扩展参考文献或后续引用。
- `finish_search(reason, evidence_ids, uncovered_constraints)`：给出结束依据、论文编号和未覆盖项。

后端为实际收集的论文分配稳定的 P 编号；引文种子和结束证据都必须引用已存在编号。参数经 Pydantic 校验，模型不能执行任意 Python 函数。单个检索动作最多返回 30 条；所有去重候选在网页分页展示。

模型能看到论文标题、年份和摘要片段；未实现全文自动下载和全文证据验证。条件覆盖估计来自既有词匹配评分，不能当成研究条件严格满足的证明。

## 预算和停止

| 深度 | 最多模型决策次数 | 最多工具调用尝试 | 检索时间上限 |
|---|---:|---:|---:|
| 快速 | 4 | 5 | 60 秒 |
| 标准 | 8 | 10 | 120 秒 |
| 深度 | 12 | 16 | 180 秒 |

这些数值是第一版工程上限，尚未依据效果与耗时实验调优。每个工具操作另有 25 秒超时。工具尝试包含参数错误、重复调用和结束动作，不能等同底层 HTTP 请求数；已有客户端可能重试或切换来源。

模型可通过结束工具或正常最终响应主动停止。已有论文时，结束说明发生格式错误也会保留结果并标记覆盖待核对，不接受未校验的证据或缺口。连续 3 次没有新增去重论文会结束；连续 3 次参数/工具错误也会结束。时间、模型次数、工具次数的上限由程序落实，批量调用中也逐个检查。

已有论文会在后续失败时保留。网页只展示固定的停止提示，不暴露内部异常、模型结束原文或检索轨迹。预算耗尽、模型中断和主动完成分别记录。无任何论文且 Agent 无法工作时返回 503，不静默运行旧工作流。

## 配置与运行

1. 在项目根目录 `.env` 设置 `DEEPSEEK_API_KEY`；不要把密钥写入聊天、代码或实验报告。
2. 可设置 `DEEPSEEK_AGENT_MODEL`，默认 `deepseek-flash`。使用模型须支持原生工具调用。
3. 按原本启动方式运行 `backend.main:app`，打开网页搜索。
4. 离线演示仍由 `SCHOLAR_FROZEN_DEMO=1` 开启，页面明确标识预存结果，不执行新 Agent。

协议参考：[DeepSeek Tool Calls 官方文档](https://api-docs.deepseek.com/zh-cn/guides/tool_calls/)。第一版使用非思考模式，保留原生 assistant/tool 消息及调用 ID 配对。

## 兼容、审计和效果边界

- API 不传 `search_strategy` 时保留 `workflow`，历史评测脚本和既有默认测试不改口径；网页显式指定 `agent`。
- 工作流 `retrieval_profile` 不参与 Agent 工具决策。Agent 候选仍使用 TRACE-Rank 评分，但不套用旧 ECS 校准和 REG-MEQ/EBP 性能结论。
- Agent 缓存使用独立的版本、模型和深度命名空间。超时或工具故障结果不缓存；缓存命中时标明历史结果，本次新增调用数为零。
- `search_process.agent` 保留动作、参数、候选增量、停止原因和预算；`metrics` 记录实际模型调用次数、工具尝试次数、已执行检索动作数和供应商返回的 Token 用量。
- 新路径接入现有冻结记录与回放。回放键排除动态倒计时，完整历史动作单独保留；正常运行中只向模型提供最近三批完整工具交互及汇总状态，控制上下文增长。
- 自动化替身验证用于证明控制流程，不证明实际模型会选择好策略。真实模型联调和与旧流程等预算质量对比应分别记录。

## 答辩前最小收敛

根据用户“能用即可，答辩后再细改”的要求，只收敛缺口判断、结束说明异常和基本页面操作。提示词与工具定义明确：未指定的年份/数据集等不能算缺口，工具执行限制与未覆盖研究条件分开。Agent 缓存及回放升级 v2，旧结果保留但不覆盖本次修正。

两个场景完成小范围真实复测：交通流量预测标准模式约 37.6 秒、118 篇候选、模型主动完成且无未指定年份误报；2023-2025 年 RAG 问答快速模式最新一次约 14.0 秒、39 篇候选、均满足年份条件并正常结束。浏览器核对摘要、分页、排序和全量 CSV 导出，无 JavaScript 异常。测试中也遇到一次结束说明格式不规范，已补保留结果的兜底并用两项回归测试覆盖。

这不是相关性或召回率基准；候选仍可能含低相关论文。完整比较、排序优化和严格证据核验按用户要求留到答辩后。操作见 `docs/答辩前运行与演示速查.md`；记录见 `tmp/agent-defense-ready/validation.json`。
